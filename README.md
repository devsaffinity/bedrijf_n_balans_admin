# Bedrijf in Balans — Admin portal

React, TypeScript and Vite admin portal for managing clients, questionnaire
submissions, payment records and uploaded documents.

## Local development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```

The current authentication, data and document actions are intentionally backed
by mock services. No credentials are embedded in the interface or source.
